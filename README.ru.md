# Code Metrics

Нативное приложение для macOS: анализ сложности, поддерживаемости и покрытия тестами.
Языки: **TypeScript, JavaScript, Go** (разбор через [tree-sitter](https://tree-sitter.github.io/)).
Всё работает локально — код никуда не отправляется.

*English version: [README.md](README.md)*

## Возможности

- **Обзор** — файлы, строки кода, комментарии, функции, maintainability, сложные функции, покрытие тестами и индекс CRAP; карточки с цветовой градацией и графики.
- **Таблицы «Файлы» и «Функции»** — сортировка, фильтры, строка подсказок «?» по каждой колонке; двойной клик открывает файл в редакторе.
- **Папки** — дерево папок с итогами; исключение папок и файлов (правый клик). Зависимости и артефакты (`node_modules`, `dist`, `vendor` и др.) пропускаются по умолчанию.
- **Покрытие тестами** — загрузка готового отчёта или запуск тестов из приложения (ссылка «Запустить тесты» на карточке).
- **Открыть в редакторе** — по умолчанию VS Code; в настройках можно выбрать Cursor, Windsurf, Zed, Sublime Text, WebStorm, IntelliJ IDEA, Xcode или системное приложение.
- **Интерфейс на английском и русском** — по умолчанию английский, переключается в настройках (⌘,).
- **Экспорт в CSV** метрик по файлам (⌘E).

## Метрики

| Метрика | Что означает |
|---|---|
| LOC / комментарии / пустые | Подсчёт строк по синтаксическому дереву |
| **CC** — цикломатическая сложность | 1 + число ветвлений (`if`, циклы, `case`, `catch`, `&&`, `||`, `??`, тернарный оператор). ≤ 10 — норма, 11–20 — повышенная, > 20 — высокая |
| **Cog** — когнитивная сложность | Как CC, но с штрафом за вложенность. ≤ 15 — норма, 16–25 — повышенная, > 25 — высокая |
| Длина, параметры, вложенность | Размер функции, число параметров, максимальная глубина вложенности |
| **MI** — индекс поддерживаемости | 0–100, формула Visual Studio (вместо объёма Холстеда — строки кода). ≥ 40 — хорошо, 20–40 — внимание, < 20 — плохо |
| **Cov** — покрытие строк | Доля строк, выполненных тестами: по проекту, файлу и функции |
| **CRAP** | `CC² × (1 − покрытие)³ + CC` — сложный и плохо покрытый код. ≤ 5 — безопасно, > 30 — «crappy» |

## Покрытие тестами

Приложение само покрытие не измеряет, а читает отчёт, созданный запуском тестов:

| Формат | Типичный файл |
|---|---|
| lcov | `coverage/lcov.info` |
| Istanbul JSON (jest, vitest, nyc, c8) | `coverage/coverage-final.json` |
| Go cover profile | `coverage.out` |

Отчёт ищется автоматически в корне проекта, либо выберите файл: **Покрытие тестами → Выбрать файл отчёта…**.

Ссылка **«Запустить тесты»** на карточке запускает в папке проекта (через login-shell, чтобы находились `node` / `go` из nvm или Homebrew):

- Go (`go.mod`): `go test -coverprofile=coverage.out ./...`
- vitest: `npx vitest run --coverage --coverage.reportsDirectory=coverage --coverage.reporter=lcov --coverage.reporter=json`
- иначе jest: `npx jest --coverage --coverageDirectory=coverage --coverageReporters=lcov --coverageReporters=json`

Полоса прогресса показывает, сколько тестовых файлов или пакетов завершено. При ошибке нажмите на красное сообщение: там команда, код завершения, вероятная причина и конец вывода. Для vitest нужен `@vitest/coverage-v8`. Если в проекте другой раннер, создайте отчёт сами и выберите файл вручную. Карточка CRAP неактивна, пока отчёт не загружен.

## Требования

- macOS 14 или новее
- Swift 5.9+ (достаточно Xcode Command Line Tools, полный Xcode не нужен)

## Сборка и запуск

```bash
./make-app.sh          # release-сборка → CodeMetrics.app (подпись ad-hoc)
open CodeMetrics.app
```

Другие цели:

```bash
swift run cmetrics <папка>   # быстрый отчёт в консоли
swift run selftest           # самопроверки анализатора, сканера и парсеров покрытия
swift build                  # debug-сборка
```

Приложение подписано ad-hoc и не нотаризовано: при первом запуске скачанной сборки используйте правый клик → **Открыть**.

## Структура

```
Sources/
  CodeMetricsCore/   сканер, анализатор на tree-sitter, модели метрик, парсеры покрытия
  CodeMetricsApp/    SwiftUI-приложение
  cmetrics/          консольный отчёт
  selftest/          самопроверки
Vendor/              грамматика tree-sitter-javascript
Resources/           иконка
make-app.sh          сборка и упаковка CodeMetrics.app без Xcode
```

Чтобы добавить язык, создайте `LanguageSpec` в `Languages.swift` и зарегистрируйте его в `LanguageRegistry`.

## Конфиденциальность

Файлы, похожие на секреты (`.env`, ключи, credentials и т. п.), не читаются. Анализ и запуск тестов происходят только на вашем компьютере.
